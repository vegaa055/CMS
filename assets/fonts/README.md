Vendored fonts. Satori (Open Graph images, `src/lib/og.tsx`) needs raw
TTF/OTF/WOFF files, so these are kept here rather than loaded via next/font/google.

- Blinker-Regular.ttf — Blinker by Supertype, SIL Open Font License 1.1 (see Blinker-OFL.txt).
  The display face for titles and headings: also loaded with next/font/local in `src/app/layout.tsx`.
- Geist-Regular.ttf — Geist by Vercel, SIL Open Font License 1.1
- UbuntuMono-Regular.ttf — Ubuntu Mono, Ubuntu Font Licence 1.0 (see UFL.txt); not currently used
