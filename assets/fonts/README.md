Fonts used to render Open Graph images (`src/lib/og.tsx`). Satori needs raw
TTF/OTF/WOFF files, so these are vendored rather than loaded via next/font.

- Geist-Regular.ttf — Geist by Vercel, SIL Open Font License 1.1
